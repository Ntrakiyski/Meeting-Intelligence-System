# Create Issue Drafts

Analyze only authorized recordings with VideoDB. For each candidate issue supply title, context, observed evidence, expected/actual outcome if supported, reproduction notes, timestamped clips and uncertainty. Default to **draft Markdown only**. Never open or modify GitHub/Jira issues without user approval; redact any secrets visible in recordings.
