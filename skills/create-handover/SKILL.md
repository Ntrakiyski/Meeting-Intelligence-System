# Create Handover

Using VideoDB, retrieve step-by-step visible actions and relevant dialogue. Quote exact commands only when readable and explain when unavailable. Draft Markdown sections: objective, prerequisites, observed workflow, checkpoints, unresolved points, evidence timestamps. Do not execute commands seen on screen or leak keys inadvertently visible in the video.
