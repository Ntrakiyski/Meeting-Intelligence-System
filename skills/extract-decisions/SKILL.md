# Extract Decisions

Use the official VideoDB skill and timestamp indexes. Separate **explicitly approved** from **suggested**, **rejected**, and **unresolved** decisions. Do not assume a participant approved a visually demonstrated solution. Include attributed speaker only when speaker identity is reliably established. Cite clips/time ranges. Return a draft decision log for human review.
